Privacy notice

Last updated: 10 November 2026

Northstar is personal Windows software for organising job applications and speculative outreach. Its desktop workspace stores records on the computer where it is installed.

The public information website and the desktop workspace are separate. This website does not display, receive or host your application records, CVs or Gmail messages.

What the desktop workspace stores

Northstar stores the records you add or import, such as employers, role descriptions, countries, application stages, notes, contacts, follow-up dates, checklists and documents. Research updates may add public job-source information and the results of source checks.

These records and documents are ordinary local files. Protect access to your Windows account and any copies or backups. Northstar is a personal local workspace, not a password-protected service for multiple users.

Optional Gmail access

You choose whether to connect Gmail through Google’s authorization screen. Northstar requests the Gmail read-only permission, which allows reading email messages and settings. It uses that permission to find application-related messages and retrieve their content for outcome matching.

  • The worker reads message metadata and relevant message bodies. It does not download email attachments as part of application-outcome tracking.
  • It stores message identifiers, timestamps, sender and subject information, a short relevant excerpt, a Gmail link, and the matching decision. It also retains screened-message identifiers and synchronization cursors so interrupted checks can resume.
  • Full message bodies are processed for matching and are not retained as a mailbox archive.
  • Only a clear outcome with a unique exact application reference or company-and-role match can update a saved application automatically. Ambiguous evidence remains available for review.
  • The worker does not send messages, reply, create drafts, mark messages as read, label, archive or delete email. It does not submit job applications.

Gmail data is used to provide the application-tracking feature described here. It is not sold, used for advertising, or transferred to an AI provider by the local Gmail and research worker. That worker does not train AI models on Gmail data.

Authorization and storage protection

Google authorization tokens and the desktop client configuration are encrypted using Windows Data Protection API for the current Windows user. The worker uses them to contact Google’s APIs over HTTPS. This encryption applies to authorization material; it does not encrypt all application records or documents.

Northstar’s exported workspace backup can contain personal documents and selected email evidence, so keep it private. Google authorization tokens and client credentials are excluded from that exported backup. A different computer or Windows account needs its own Gmail connection.

Network connections and other services

The optional Gmail worker contacts Google to authorize access and read messages. The research worker requests public employer and government job pages. These services receive the ordinary technical information needed to answer requests, such as an IP address. Their own privacy practices also apply.

Opening an employer, application, Google or other external link takes you to that service. Review what you share there. The local background worker does not upload your CV or application records to those job sites.

Your controls and retention

You can pause background checks in Northstar. Disconnecting Gmail in Background settings removes the saved Gmail tokens from that installation and stops new Gmail checks. Existing application history and selected email evidence remain in the workspace.

You can also remove Northstar’s access through your Google Account connections. Google may require you to reconnect if authorization expires or is revoked.

Northstar keeps local records until you remove the local data or replace it through supported workspace actions. To remove all retained copies, stop the background worker and remove the local workspace data and any backups or exported files you keep. Disconnecting Gmail alone does not erase historical records.

This information website

These static pages contain no application forms, custom cookies, advertising scripts or analytics scripts. The information website is hosted on GitHub Pages. GitHub logs and stores visitors’ IP addresses for security purposes, including when visitors are not signed into GitHub. That hosting activity is separate from your local Northstar workspace. See GitHub Pages’ data-collection explanation and GitHub’s privacy statement.

Changes to this notice

The notice should be updated if Northstar’s data handling changes. The date above identifies this version. Any future optional AI or hosted feature needs its own clearly disclosed data flow before it is connected.
